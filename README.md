# 🩸 Blood Cancer Prediction

A machine learning project focused on predicting blood cancer characteristics. This repository contains the core predictive models, analytical result generation, and an interactive front-end demo built completely inside Jupyter Notebooks.

---

## 📂 Repository Structure

The project is broken down into three distinct notebook components:

*   **`Blood_cancer_Prediction_Brain.ipynb`**: The foundational pipeline containing data preprocessing, feature engineering, and model training.
*   **`Blood_Cancer_Prediction_result.ipynb`**: Analyzes the model metrics, validation accuracy, performance evaluations, and prediction results.
*   **`Blood_Cancer_Frontend_Demo.ipynb`**: A user-friendly demonstration interface designed to simulate input data entry and display predicted outcomes.

---

## 🛠️ Built With

*   **Python 3.x** - Core programming language.
*   **Jupyter Notebook** - Development environment for the model and UI demo.
*   **Data Science Stack** - Libraries such as `pandas`, `numpy`, and `scikit-learn` for data handling and modeling.
*   **Visualization Stack** - Tools like `matplotlib` or `seaborn` for graph generation.

---

## 🚀 Getting Started

### Prerequisites
Make sure you have Python and `pip` installed on your machine. You will also need Jupyter Notebook or JupyterLab.

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd Blood-Cancer-Prediction
   ```

2. **Install required packages:**
   ```bash
   pip install numpy pandas scikit-learn matplotlib seaborn jupyter
   ```

3. **Launch the notebooks:**
   ```bash
   jupyter notebook
   ```
   *Open `Blood_cancer_Prediction_Brain.ipynb` first to understand the model training flow, or run `Blood_Cancer_Frontend_Demo.ipynb` to see the live prediction interface.*
